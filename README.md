## 💡 Core Philosophy: GNVE | 核心设计哲学：生成式非言语表达
In the era of AGI, interaction should transcend rigid, pre-defined VUI animations. We introduce **Generative Non-Verbal Expression (GNVE)**. The AI's visual feedback is treated as its "body language," dynamically adapting to the human-AI conversational flow through sensory perception.

在 AGI 时代，人机交互应当超越死板、预设的动画。我们引入了**生成式非言语表达（GNVE）**概念。AI 的视觉反馈被视为其“身体语言”，通过感觉通道，动态自适应人机对话的节奏。

## 🛠️ Dynamic Adaptive Physics Model | 动态自适应数学物理模型 (v3.0)
Instead of hardcoding animation curves, we map the AI's internal cognitive/affective states directly to physical spring-damper parameters:

我们拒绝硬编码动画曲线，而是将 AI 的内部认知/情感状态直接映射到弹簧-阻尼等基础物理属性中：

$$\text{Damping (阻尼感)} \propto \text{Intimacy (亲密度)} \times (1 - \text{Urgency (紧急度)})$$

### Physical Parameter Definitions | 物理参数定义:
1. **Damping (阻尼感)**: Controls the softness and smooth deceleration of transitions (e.g., from evaluating back to listening). Higher damping represents **"Visual Yielding (视觉让步)"**, giving the user a gentle, respectful pause.
   控制状态过渡的平滑与温退程度。高阻尼体现为**“视觉让步”**（如：从黄色评估退回蓝色聆听），给用户提供温柔、自然的停顿缓冲。
2. **Frequency (频率)**: Controls the pacing and urgency of the pulse (e.g., breathing speed or vortex rotation rate).
   控制状态脉动（如呼吸、漩涡旋转）的急促程度，直接反向影响人类在边缘视觉中的语速直觉。
3. **Color Shift Rate (色彩漂移速度)**: Controls the speed of color transitions during state changes (e.g., instant transitions in urgent tasks vs. bleeding-in transitions in casual chats).
   控制状态转换时的颜色渐变速度（如紧急任务时的瞬时切换，与闲聊时的融化过渡）。

## 🚀 Embodied Roadmap | 具身非言语表达演进路线

本项目将从纯粹的屏幕/指示灯交互，逐步向多维度的具身物理反馈演进：

- [ ] **v3.1 (Visual Dialects)**: Implement rendering algorithms for different screen/LED hardwares based on the damping formula. (基于阻尼公式，实现适配不同屏幕与 LED 硬件的渲染算法)
- [ ] **v4.0 (Thermal Dynamics)**: Explore micro-temperature changes on device surfaces to convey thermal pacing. (探索设备表面微温变化的温度动力学表达)
- [ ] **v5.0 (Haptic Pacing)**: Implement subtle haptic vibration mapping based on breathing rhythms. (实现带有呼吸节奏的细腻触觉反馈)
- [ ] **v6.0 (Ultrasonic Non-contact tactile)**: Explore micro-airflow/directional tactile sensation in the air via ultrasonic arrays. (探索通过超声波阵列在空中产生的微弱气流与定向震动感)
